### A｜Google 发布 Gemini 3.8 Live 与扩展思考版实时语音模型

Gemini 3.8 Live 面向低延迟语音交互，Extended Thinking 版可在持续说话的同时执行后台推理与异步工具调用；两者支持音频、图像、视频和文本输入，最长 128K 上下文，并通过 API、AI Studio、Vertex AI 等渠道分发。

- 真实日期：2026-09-15
- 重要性：实时语音 Agent 开始把长推理、工具等待和自然对话并行化，但客户端必须从单一 turnComplete 信号迁移到显式交互状态管理。
- 建议动作：优先复测抢话、异步工具超时和状态机恢复；把首音延迟、任务完成率、误打断与单位分钟成本分开记录。
- 来源：[Google DeepMind 官方模型卡](https://deepmind.google/models/model-cards/gemini-3-8-audio/)；[Gemini API 官方扩展思考文档](https://ai.google.dev/gemini-api/docs/live-api/thinking)

### A｜Google 在 GKE 推出开源 Agent Substrate 高密度沙箱运行时

Agent Substrate 以 Kubernetes 为基础，为长期 Agent 提供 microVM 或 gVisor 隔离、网络出口控制、状态快照和亚秒级恢复；官方称每台主机可容纳逾千个休眠 Agent，并可在任意 Kubernetes 环境运行。

- 真实日期：2026-09-15
- 重要性：Agent 基础设施的瓶颈正从模型调用转向长期环境的隔离、暂停恢复和空闲算力成本，这一开源运行时给自建 Agent 平台提供了可直接评估的底座。
- 建议动作：只在非生产集群试用，重点验证内核逃逸、凭据注入、网络白名单、快照一致性和高并发恢复；官方仓库仍明确处于早期开发。
- 来源：[Google Cloud 官方公告](https://cloud.google.com/blog/products/containers-kubernetes/agent-substrate-available-on-gke)；[Agent Substrate 官方仓库](https://github.com/agent-substrate/substrate)
