### A｜Google Gemini API 停用 Imagen 4 三个正式模型端点

Google 按既定计划于 8 月 17 日关闭 `imagen-4.0-generate-001`、`imagen-4.0-ultra-generate-001` 与 `imagen-4.0-fast-generate-001`，官方建议迁移到 `gemini-3.1-flash-image`。这是此前公告在本次 24 小时窗口内正式生效的兼容性事件，并非当日新发布模型。

- 类型：重大事件
- 事件日期：2026-08-17
- 重要性：仍调用 Imagen 4 固定模型 ID 的图像生成、室内设计渲染和自动化内容管线可能直接失败；替代模型的画质、提示词遵循、延迟与成本也可能改变。
- 建议动作：立即盘点 Gemini API 中的 Imagen 4 模型 ID，先用回归样例比较迁移前后的构图、文字、人物一致性与费用，再切换生产流量。
- 来源：[Gemini API 官方停用时间表](https://ai.google.dev/gemini-api/docs/deprecations)；[Gemini API 官方更新日志](https://ai.google.dev/gemini-api/docs/changelog)

### A｜Autodesk AEC 与制造数据模型 API 新计费方案正式生效

Autodesk Platform Services 按六月公告于 8 月 17 日开始对 AEC Data Model API 和 Manufacturing Data Model API 引入新计费：免费层继续保留有限用量，符合条件的 Autodesk 产品订阅包含月度额度，超额使用需采用 Flex 预付或按量付费。

- 类型：重大事件
- 事件日期：2026-08-17
- 重要性：这些 API 是 BIM/AEC 数据抽取、自动检查、报表、数字孪生和 AI 辅助设计工作流的基础设施；计费与团队归属规则会直接改变规模化 Agent 和数据流水线的单位经济性。
- 建议动作：核对 APS 应用与产品订阅是否位于同一团队，按真实调用量测算免费额度、订阅包含量和超额费用，并为超限或权限错配设置告警。
- 来源：[Autodesk APS 官方计费公告](https://aps.autodesk.com/blog/coming-august-data-model-apis-included-subscriptions-plus-flexible-ways-scale)；[Autodesk AEC Data Model API 官方说明](https://aps.autodesk.com/blog/files-data-unlocking-data-driven-aec-workflows-aec-data-model-apis)

### A｜ForgeWM：渐进因果训练的少步动作条件视频世界模型

ForgeWM 通过领域适配、教师强制因果训练、因果一致性蒸馏和在策略分布匹配，把双向动作条件视频生成器压缩为 1、2、4 步学生模型。它同时提供低延迟交互草稿与回放精修双路径，在 Minecraft 和手柄控制 FPS 轨迹上改善画质、动作方向与鼠标控制一致性。

- 类型：前沿论文
- 事件日期：2026-08-17
- 重要性：为可交互游戏世界模型、实时仿真和动作条件视频生成提供可复现的低延迟训练与部署范式。局限是当前证据集中在游戏轨迹，训练资源门槛、长时稳定性和跨环境泛化仍需复测。
- 建议动作：复测一至四步模型的端到端延迟、长轨迹漂移与动作一致性，审计数据许可后再评估进入交互式世界模型管线。
- 来源：[arXiv 论文页](https://arxiv.org/abs/2608.14022)；[作者项目页](https://asdfo123.github.io/ForgeWM)；[论文官方代码](https://github.com/asdfo123/ForgeWM)

### A｜Onto-EV-WM：用本体约束世界模型的故障诊断与闭环修复

该工作在 EV-WM 之上增加本体化诊断与验证门控修复接口，把未满足的任务谓词、可用纠正路径和修复后的验收结果显式记录，再由确定性规则选择修复路线。完整配置在 PointMaze 和 LIBERO 系列仿真中改善终态距离与修复成功率。

- 事件日期：2026-08-17

### A｜HumanForge：带多智能体伪造理由的人本深伪视频基准

HumanForge 汇集超过 1.8 万段音频驱动、姿态驱动、语义驱动和交互式合成人物视频，并用六个专职智能体组成的 Gen2Anno 流水线生成真伪、生成器归因与对比式伪造理由标注。基准显示现有检测器和视觉语言模型在跨生成器泛化、扰动鲁棒性与可解释推理上仍有明显缺口。

- 类型：前沿论文
- 事件日期：2026-08-17
- 重要性：可用于内容平台、广告审核、数字人和视频生成产品评估检测器是否能跨模型识别复杂交互型伪造。局限是数据与代码尚未实际公开，真实分发压缩和未知生成器表现仍待复现。
- 建议动作：等待数据与代码正式开放后核验许可证、真实视频覆盖度和基准可复现性；在此之前只保留 pending 工程候选，不猜仓库地址。
