### B｜Redmine Agent 1.0 上架：以现有用户权限连接工单与 MCP

RedmineUP 在 Redmine 官方插件目录登记 Agent 1.0.0，提供基于工单历史的回复草稿、问题及 Wiki 等摘要，并内置 MCP 服务供 Claude、ChatGPT、Codex 和 Gemini CLI 操作工单与附件。官方说明支持 API key 或 OAuth，沿用连接用户的 Redmine 权限，摘要刷新只处理新增活动。

- 事件日期：2026-10-25
- 内容类型：行业事件
- 重要性：项目管理与客服工单开始成为 Agent 的直接工作入口，权限继承、增量摘要和使用统计可作为企业接入方案的比较维度。
- 建议动作：适合已使用 Redmine 的团队评估；先在测试环境核对用户权限、附件访问和外部模型数据流。产品有免费 Light 与付费 PRO，部分功能属 PRO；本批仅核验发布与产品说明，未安装或验证安全效果。目录未提供代码仓库，仓库URL保持pending。

### B｜SprongMotion 1.1 更新运行时 API，并同步发布 Blender 插件

SprongMotion 运行时 1.1.0 将公开接口改为结构体与配置字段，统一线程错误信息，并支持多个线程共享一个模型生成动作。作者声明同一精确构建、模型与设置下输出与 1.0.1 逐位一致；Blender 1.1.0 同步提供内置运行时和既有 SprongMotion-14M 模型的各平台包。这是工程接口升级，模型仍为 1.0。

- 事件日期：2026-10-26
- 内容类型：行业事件
- 重要性：轻量文本转动作工具继续完善 C 与 Blender 接入方式，适合跟踪离线角色动画原型和浏览器演示的工程成本。API 改名意味着现有集成需要迁移。
- 建议动作：先对照官方迁移表审查旧接口，再在测试项目比较输出和线程行为。模型包总计约2000万参数，14M指动作生成器；公开模型卡注明英文输入、22关节且无手指、动作可能僵硬或滑步。未安装、运行或验证作者的性能与一致性声明。
- 来源：[官方运行时1.1.0发布与迁移表](https://github.com/SegerEnd/sprongmotion-runtime/releases/tag/v1.1.0)、[官方Blender1.1.0发布](https://github.com/SegerEnd/sprongmotion-blender/releases/tag/v1.1.0)、[官方运行时版本API与精确时间](https://api.github.com/repos/SegerEnd/sprongmotion-runtime/releases?per_page=3)、[官方模型卡及使用限制](https://huggingface.co/SegerEnd/SprongMotion-14M/raw/main/README.md)

### A｜前沿论文：ArtifactWorld：用视频生成模型规模化修复 3DGS 伪影

ArtifactWorld 面向稀疏视角 3DGS 的几何和光度伪影，先建立细粒度伪影分类并构造 10.75 万对视频训练数据，再用同构预测器生成伪影热图，引导共享视频扩散骨干进行按强度、跨时间一致的局部修复。

- 事件日期：2026-04-14
- 内容类型：前沿论文（摘要级）
- 重要性：适合稀疏拍摄的房产、室内空间和数字孪生资产修复，可把逐场景人工清理转化为可批处理的生成式后处理流程。
- 建议动作：应重点验证真实室内外采集、强遮挡和大视角变化下的几何保真度，并关注完整训练数据、训练代码与跨 3DGS 管线泛化。 局限：摘要与官方仓库 README 级解读；论文自报领先结果尚未复核完整实验。官方仓库已提供推理代码、权重和 1.28K 基准子集，但 10.75 万规模训练数据与训练代码仍计划后续发布。
- 来源：[arXiv 原始论文](https://arxiv.org/abs/2604.12251)、[作者代码](https://github.com/fyting/ArtifactWorld)

### A｜前沿论文：SceneMosaic：高效生成多样且可直接用于仿真的室内场景

SceneMosaic 先用图像先验快速生成候选场景，再由 VLM Agent 按局部单元演化布局并组合为全局结果；在 SceneEval-100 上以 24 倍速度达到强 Agent 基线的语义布局质量，同时降低物理违规。

- 事件日期：2026-09-04
- 内容类型：前沿论文（摘要级）
- 重要性：适合具身仿真、游戏关卡和室内设计方案的快速扩量，可把“可看”场景推进到“可交互、可训练”。
- 建议动作：与 SimReady 资产标准、机器人任务约束和真实扫描场景结合，形成可自动验收的空间生成流水线。 局限：摘要级解读；结果集中于 SceneEval-100，真实资产碰撞、材质、可达性和复杂房间关系仍需独立验证。
- 来源：[arXiv 原始论文](https://arxiv.org/abs/2609.05594)、[作者代码](https://github.com/rxjfighting/SceneMosaic)
