## 今日重点

### A｜Google Cloud API Gateway 可将现有 REST 接口直接发布为 MCP 工具

Google Cloud 宣布 API Gateway 的 MCP 支持进入公开预览。团队可在 OpenAPI 3.x 规范中添加 MCP 元数据，由网关在 /mcp 端点完成工具发现、JSON-RPC 到 REST 的转码，并沿用已有 JWT、API Key、配额和日志策略，无需另建 MCP 服务器。

- 事件日期：2026-09-24
- 内容类型：行业事件
- 重要性：它把 Agent 工具化从单独维护服务器下沉到企业 API 网关层，可减少重复基础设施，同时让 REST 与 MCP 共享认证、配额和审计路径。当前工具发现默认可公开，生产环境仍需主动用 JWT 保护。
- 建议动作：选择一个低风险内部 REST API 做试点，启用受保护的 tools/list，验证权限继承、配额共享、深层 schema 截断和 204 响应限制，再决定是否扩大暴露范围。
- 来源：[Google Developers Blog 官方公告（9 月 24 日）](https://developers.googleblog.com/en/turn-your-rest-apis-into-mcp-tools-with-google-cloud-api-gateway/)；内部发现源 09.25 AI 风向标（发现源）

### A｜Black Forest Labs 发布 FLUX 3 Action 开放权重世界动作模型

FLUX 3 Action 是 70 亿参数世界动作模型，输入相机帧、机器人状态和文字指令，并联合去噪下一段动作与未来视频帧。官方同时提供适配底座、DROID 与 SO-101 策略、推理与完整微调代码；DROID 版本在 RoboLab-120 报告 42.92% 任务成功率。

- 事件日期：2026-09-24
- 内容类型：行业事件
- 重要性：图像与视频生成骨干正在直接进入机器人控制，且此次提供可运行权重、训练代码和具体硬件契约，具备进入物理 AI 工程评估的条件。不过权重采用 FLUX Kommunity License，并非宽松开源许可证。
- 建议动作：先在仿真与录制观测上复现推理和显存占用，核对许可证与动作单位；真实机械臂测试必须启用速度、力和工作区限制，并保留硬件急停。
- 来源：[Black Forest Labs 官方 FLUX 3 Action 模型集合](https://huggingface.co/collections/black-forest-labs/flux-3-action)；[Black Forest Labs 官方训练与推理仓库](https://github.com/black-forest-labs/flux-action)；内部发现源 09.25 AI 风向标（发现源）

### A｜Google 用 MaxText 在 TPU 上复现 OLMo 3 7B 训练流程

Google Cloud 与 AI2 团队公布 OLMo 3 7B 在 MaxText/JAX/TPU 上的预训练和中段退火复现。转换后与 PyTorch 参考的 KL 约为 1.5e-3、全上下文 top-1 一致率 98.75%；持有集评估还发现了会制造虚假低损失的数据加载双重分片问题。

- 事件日期：2026-09-24
- 内容类型：行业事件
- 重要性：该案例把大模型复现从损失曲线相似提升到框架转换、断点续训、资源缩放和持有集一致性共同验收，并显示 16×256 注意力头形状可在 Ironwood 上提升 12.4% 吞吐。
- 建议动作：参考其成对断点续训和持有集差分流程，给自有训练管线加入数据指纹、迭代器状态和 logits 对齐检查，避免把数据泄漏或重放错误误判为性能提升。
- 来源：[Google Developers Blog 官方复现案例（9 月 24 日）](https://developers.googleblog.com/reproducing-olmo-3-7b-pre-training-in-maxtext-case-study-of-large-scale-training-on-tpus/)；[MaxText 官方 GitHub 仓库](https://github.com/AI-Hypercomputer/maxtext)；内部发现源 09.25 AI 风向标（发现源）

### B｜Midjourney 更新局部编辑、实时风格预览与无缝平铺

Midjourney 在 Alpha 站点加入基于当前提示词的风格实时预览；点击缩略图即可按该风格生成。编辑模型改为尽量只改变选区像素，降低多轮修补的整体画质退化；V8.1 与 V8.2 的 --tile 也改善了重复纹理接缝。

- 事件日期：2026-09-24
- 内容类型：行业事件
- 重要性：生成式设计竞争正在从单次出图转向可预览、可局部迭代和可重复生产的工作流，直接影响品牌素材、纹理和室内效果图的修改效率。
- 建议动作：用固定品牌素材测试多轮局部编辑的非选区漂移、角色一致性和 tile 接缝，并记录预览图与最终出图的风格偏差。
- 来源：[Midjourney 官方更新（9 月 24 日）](https://updates.midjourney.com/edit-updates-thumbnail-previews-and-more/)；[Midjourney Alpha 官方变更日志](https://updates.midjourney.com/alpha-changelog-9-23-26/)；内部发现源 09.25 AI 风向标（发现源）

### B｜Notion API 将限流等待时间写入响应体，方便 MCP 客户端自动重试

Notion 开发者平台更新 429 与 529 响应：只要包含 Retry-After 头，就会在响应体 additional_data.retry_after 中重复等待时间；同时新增端点自限流和连接被限制两类原因码，并明确工作区 429 由所有连接共享。

- 事件日期：2026-09-24
- 内容类型：行业事件
- 重要性：无法稳定读取响应头的 MCP 客户端也能获得确定的退避时间，可减少 Agent 在限流时盲目重试；共享工作区限额仍意味着多 Agent 会互相影响。
- 建议动作：更新 Notion 工具适配层，优先读取响应体等待时间并记录 rate_limit_reason；为多 Agent 加工作区级并发协调和抖动退避。
- 来源：[Notion 开发者官方变更日志（9 月 24 日）](https://developers.notion.com/page/changelog)；内部发现源 09.25 AI 风向标（发现源）

### A｜minWM：构建实时交互视频世界模型的全栈开源框架

minWM 提供从数据构建、相机控制微调、自回归扩散训练、少步蒸馏到流式推理的端到端流程，可把 Wan 2.1、HunyuanVideo 1.5 等双向视频模型改造成相机可控、低延迟的自回归世界模型。

- 事件日期：2026-09-23
- 内容类型：前沿论文
- 重要性：它为世界模型与交互仿真团队提供可复现的工程底座，降低从通用视频模型搭建实时闭环系统的门槛。
- 建议动作：先复现公开检查点的少步推理与长时滚动稳定性，再评估接入新的数据分布和机器人动作条件。
- 来源：[arXiv 论文页](https://arxiv.org/abs/2605.30263)；[作者官方项目仓库](https://github.com/shengshu-ai/minWM)

### A｜面向可审计城市 DSM 重建的建筑感知卫星 3DGS 智能体流程

该研究把建筑分割掩码作为语义先验，并由智能体式控制器选择、验证和记录 DSM 重建策略，使卫星 3DGS 优先改善分析人员关注的建筑区域；摘要报告建筑区 DSM MAE 从 0.844 米降至 0.806 米。

- 事件日期：2026-09-23
- 内容类型：前沿论文
- 重要性：它把城市三维重建从平均画质优化推进到业务关键区域和可追溯决策，适合灾害响应、城市监测与地理空间数字孪生。
- 建议动作：在多城市、多传感器数据上复核提升，并检查建筑掩码误差是否会把重建能力错误分配到非关键区域。
- 来源：[arXiv 论文页](https://arxiv.org/abs/2609.25578)

### A｜Skytopia：基于动作条件潜在世界模型的单目无人机导航

Skytopia 训练动作条件世界模型的潜在表示，但部署时丢弃未来帧预测器，让同一策略覆盖点目标、图像目标和无目标导航。摘要称移除预测器可减少 59.4% 推理成本，并在真实无人机上实现零微调迁移。

- 事件日期：2026-09-23
- 内容类型：前沿论文
- 重要性：它为边缘无人机提供比逐步生成未来图像更轻的世界模型路线，可用于巡检、空间理解和弱算力导航。
- 建议动作：重点测试动态障碍、弱纹理、极端光照和长航迹，真实部署前建立失败停机和人工接管机制。
- 来源：[arXiv 论文页](https://arxiv.org/abs/2609.26007)
