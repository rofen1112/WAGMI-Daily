## 今日重点

### A｜通义千问发布 Qwen3.8-Omni-Flash，把音视频理解接入 Agent 交付

Qwen3.8-Omni-Flash 支持文本、图片、音频和视频输入、文本输出，以及 100 万 token 上下文、工具调用、联网搜索和多声道音频；官方将其定位为可规划任务并完成音视频工作流的全模态 Agent 模型。

- 真实日期：2026-09-18
- 重要性：长音视频不再只是被动摘要素材，而可进入检索、规划、工具调用和内容交付链路；这会直接影响会议分析、媒体生产、研究取证与多模态 Agent 的成本结构。
- 建议动作：先以真实长视频、多人会议和跨模态检索任务复测准确率、时间定位、工具调用稳定性与费用，不把厂商基准直接视为生产结论。
- 来源：[Qwen 官方发布页](https://qwen.ai/)；[阿里云百炼官方模型文档](https://help.aliyun.com/zh/model-studio/qwen3-8-omni-flash)

### A｜Qwen3.8-LiveTranslate 上线，覆盖 60 种源语言与 29 种语音输出

Qwen3.8-LiveTranslate-Flash-Realtime 面向实时音视频同传，支持音频与图像输入、文本与音频输出，可识别 60 种源语言并为 29 种语言生成语音；官方称平均延迟由 2.8 秒降至 2.3 秒。

- 真实日期：2026-09-18
- 重要性：同传模型开始同时处理说话人、视觉上下文与语音输出，适合跨语言会议、直播和现场协作，但延迟、术语一致性与说话人归属仍需在真实噪声环境验证。
- 建议动作：用多人抢话、专有名词、口音、弱网与摄像头上下文建立回归集，并单独评估翻译正确性、说话人识别、端到端延迟和隐私边界。
- 来源：[Qwen 官方发布页](https://qwen.ai/)；[阿里云百炼官方模型文档](https://help.aliyun.com/zh/model-studio/qwen3-8-livetranslate-flash-realtime)

### A｜Claude Code 2.1.277 支持 AGENTS.md，2.1.278 调整企业自动模式分类器

Claude Code 2.1.277 在项目没有 CLAUDE.md 时读取 AGENTS.md，并增强网关代理、静态请求头、后台任务提示及多项恢复稳定性；2.1.278 又让 API、企业与主流云平台默认使用服务端自动模式分类器，并在状态页显示其位置。

- 真实日期：2026-09-19
- 重要性：AGENTS.md 兼容可减少多工具仓库维护重复说明，网关与自动模式变化则直接影响企业部署的出口控制、分类器成本、可观测性和故障行为。
- 建议动作：升级前验证 AGENTS.md 回退优先级、网关代理 DNS 边界、静态头部泄露风险、无头会话错误退出，以及服务端分类器的计费提示和禁用开关。
- 来源：[Claude Code 2.1.277 官方发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)；[Claude Code 2.1.278 官方发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)
