## 01 Google DeepMind 发布 Gemini Robotics 2 与 ER 2

**优先级：A｜板块：AI 产品 / 模型、AI Agent、AI 3D / 世界模型**

Google DeepMind 发布 Gemini Robotics 2、Gemini Robotics ER 2 和 On-Device 2，覆盖全身视觉语言动作控制、具身推理、连续视频进度判断、自我纠错、多机器人协作和本地部署。ER 2 已通过 Gemini API 与 Google AI Studio 向开发者开放。

这一体系把高层物理推理与低层 VLA、导航或机器人 API 解耦，正在形成更接近智能空间控制层的物理 Agent 架构。官方示例仓库 `google-gemini/robotics-samples` 已加入 GitHub 强制候选。

## 02 OpenAI 下调 GPT-5.6 Luna 与 Terra 价格

**优先级：A｜板块：AI 产品 / 模型、AI Agent、市场 / 商业模式**

OpenAI 将 GPT-5.6 Luna API 价格下调 80%、Terra 下调 20%，并推出取代 Priority Processing 的 Sol Fast 模式。Sol Fast 在智能水平不变的前提下最高可达标准处理的 2.5 倍速度，价格为标准模式的两倍。

模型调度将更适合按规划、执行、测试和评估拆分，后续需要关注每个成功任务的总成本，而不是只看 token 单价。

- [OpenAI 官方价格与性能说明](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/)

## 03 Agent harness 设计显著影响 ARC-AGI-3 结果

**优先级：A｜板块：AI Agent、使用技巧 / 工作流**

OpenAI 发现通用评测 harness 丢弃私有推理并滚动截断历史，导致 Agent 反复从头理解任务。改用 Responses API 保留推理并启用 compaction 后，GPT-5.6 Sol 的公开集得分从 13.3% 提升到 38.3%，输出 token 降至约六分之一。

这说明 Agent 评测必须同时记录模型、API、记忆、压缩策略、上下文上限和工具协议，否则不同系统之间的结果不可直接比较。

- [OpenAI ARC-AGI-3 harness 分析](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)
