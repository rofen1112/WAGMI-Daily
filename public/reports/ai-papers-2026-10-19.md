### ArtifactWorld：用视频生成模型规模化修复 3DGS 伪影

英文原题：ArtifactWorld: Scaling 3D Gaussian Splatting Artifact Restoration via Video Generation Models

- 作者：Xinliang Wang、Yifeng Shi、Zhenyu Wu
- 原始首次提交：2026-04-14；本次收录：2026-10-19。这是既有研究复核，不是当天新发表。
- 来源：[arXiv 原文](https://arxiv.org/abs/2604.12251)、[论文 PDF](https://arxiv.org/pdf/2604.12251)
- 实际阅读深度：摘要级；原解读时间：2026-10-02T07:35:00+08:00；本次原文复核：2026-10-18T23:38:17.313Z。未读取 PDF 全文或执行复现。
- 中文摘要：ArtifactWorld 面向稀疏视角 3DGS 的几何和光度伪影，先建立细粒度伪影分类并构造 10.75 万对视频训练数据，再用同构预测器生成伪影热图，引导共享视频扩散骨干进行按强度、跨时间一致的局部修复。
- 核心贡献：建立覆盖多类 3DGS 缺陷的细粒度分类与大规模配对视频数据；用同构预测器定位结构缺陷并生成伪影热图；以伪影感知三路融合在统一视频扩散骨干内完成时空修复
- 行业价值：适合稀疏拍摄的房产、室内空间和数字孪生资产修复，可把逐场景人工清理转化为可批处理的生成式后处理流程。
- 限制：摘要与官方仓库 README 级解读；论文自报领先结果尚未复核完整实验。官方仓库已提供推理代码、权重和 1.28K 基准子集，但 10.75 万规模训练数据与训练代码仍计划后续发布。
- 未来趋势与建议：应重点验证真实室内外采集、强遮挡和大视角变化下的几何保真度，并关注完整训练数据、训练代码与跨 3DGS 管线泛化。
- 官方代码关系：[fyting/ArtifactWorld](https://github.com/fyting/ArtifactWorld)，由[论文明确链接](https://arxiv.org/abs/2604.12251)，本次核对 README 身份，未运行代码

### SceneMosaic：高效生成多样且可直接用于仿真的室内场景

英文原题：SceneMosaic: Efficient and Diverse Simulation-Ready Scene Generation via Hybrid Agentic Layout Evolution

- 作者：Xingjian Ran、Xiaoye Mo、Sihao Liu、Jianyu Zhang、Li Luo、Bo Dai
- 原始首次提交：2026-09-04；本次收录：2026-10-19。这是既有研究复核，不是当天新发表。
- 来源：[arXiv 原文](https://arxiv.org/abs/2609.05594)、[论文 PDF](https://arxiv.org/pdf/2609.05594)
- 实际阅读深度：摘要级；原解读时间：2026-09-11T08:50:28.282Z；本次原文复核：2026-10-18T23:38:17.313Z。未读取 PDF 全文或执行复现。
- 中文摘要：SceneMosaic 先用图像先验快速生成候选场景，再由 VLM Agent 按局部单元演化布局并组合为全局结果；在 SceneEval-100 上以 24 倍速度达到强 Agent 基线的语义布局质量，同时降低物理违规。
- 核心贡献：融合参数化图生 3D 与 VLM Agent 的互补优势；按局部场景单元独立演化并组合多样结果；兼顾生成效率、布局质量和物理有效性
- 行业价值：适合具身仿真、游戏关卡和室内设计方案的快速扩量，可把“可看”场景推进到“可交互、可训练”。
- 限制：摘要级解读；结果集中于 SceneEval-100，真实资产碰撞、材质、可达性和复杂房间关系仍需独立验证。
- 未来趋势与建议：与 SimReady 资产标准、机器人任务约束和真实扫描场景结合，形成可自动验收的空间生成流水线。
- 官方代码关系：[rxjfighting/SceneMosaic](https://github.com/rxjfighting/SceneMosaic)，由[论文明确链接](https://arxiv.org/abs/2609.05594)，本次核对 README 身份，未运行代码
