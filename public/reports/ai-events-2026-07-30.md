### 2. Perplexity 开源 Numbat，为编码 Agent 提供终端阻断、遥测与取证

- **ID**：`ai-2026-07-30-perplexity-numbat-agent-security`
- **事件日期**：2026-07-29
- **摘要**：Perplexity 发布并开源 Numbat。它以静态 Go 二进制运行于 macOS、Linux 和 Windows，通过 Agent hooks 执行检测与预操作阻断，把会话文件整理为统一 NDJSON 时间线，并可作为本地 OTLP 接收器。官方称其内置 52 条规则、覆盖 11 类行为，已用于数千台内部终端上的 Claude Code、Codex、OpenCode 和 Pi。
- **为什么重要**：Agent 安全控制从模型层提示与审批，推进到可跨 Agent 复用的终端级观测、阻断和事后取证；这更贴近长时运行编码 Agent 的真实企业风险面。
- **行动**：先在只读开发机运行 `numbat scan`，评估误报、日志敏感性和规则覆盖，再小范围启用 pre-action blocking；将遥测留存、隐私边界与响应责任写入部署策略。
- **Priority / Boards**：A；AI Safety / Governance、AI Agent、AI Coding
- **SourceType / Verification**：official、official-repo / verified
- **Entities**：Perplexity、Numbat、Claude Code、Codex、OpenCode、Pi
- **RepoCandidates**：`perplexityai/numbat`
- **Sources**：[Perplexity 官方研究文章](https://research.perplexity.ai/articles/securing-agents-across-perplexity%E2%80%99s-client-endpoints-with-numbat) · [官方 GitHub](https://github.com/perplexityai/numbat) · 内部发现源 AI 风向标（discovery）
