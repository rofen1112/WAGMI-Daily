## 今日重大事件

### A｜Google 在 Gemini Live 上线无障碍视觉辅助 Guided Vision

Google 于 10 月 1 日正式推出 Gemini Live 的 Guided Vision，通过实时语音描述、连续追问和取景引导帮助盲人及低视力用户理解周边环境。功能覆盖支持 Gemini Live 的 Android 9 及以上设备，并与 Aira 及超过 1,000 名测试者共同建立安全护栏。

- 事件日期：2026-10-01
- 重要性：这不是单次识图，而是把相机、连续对话和主动取景提示组合为实时辅助界面，显示多模态模型正进入高频、强情境的无障碍使用场景。
- 建议动作：关注真实设备的延迟、错误类型和地区可用性；产品设计中明确保留其非导航工具、非医疗设备且不能替代白杖等安全边界。
- 来源：[Google 官方发布说明](https://blog.google/innovation-and-ai/products/gemini-app/guided-vision-gemini-live/)

### A｜ComfyUI 推出可在画布中规划并执行工作流的 Comfy Agent

ComfyUI 在 Comfy Cloud 上向所有用户开放 Comfy Agent 测试版，用户可用自然语言让代理规划、搭建、运行和迭代图像或视频工作流。它能理解画布、资产、节点和现有工作流，并支持最多 5 个并行对话；Desktop 版本计划数周后推出。

- 事件日期：2026-10-01
- 重要性：创作 Agent 开始直接操作可检查的节点图，而不是只返回成品。这种人与 Agent 共用同一画布的形态，可能显著降低复杂生成工作流的搭建、调试和批量试验成本。
- 建议动作：用真实项目测试节点选择、失败恢复、模型成本和人工中途修改后的同步；避免把云端测试版误写成已在本地桌面版全面可用。
- 来源：[ComfyUI 官方发布文章](https://blog.comfy.org/p/comfy-agent-the-first-agent-for-craft)

### A｜Claude Code 2.1.287 引入可改写深层行为的 Claude Mods

Anthropic 于 10 月 1 日发布 Claude Code 2.1.287，新增 Claude Mods，使插件能够修改更深层的运行行为；同时加入可选的“你应该知道”内置 Mod，由侧边 Agent 提醒用户或 Claude 可能忽略的问题。版本还增加 Agent 会话筛选和 MCP URL 提示支持，并修复多项远程、沙箱和权限问题。

- 事件日期：2026-10-01
- 重要性：Mods 把插件从增加命令和资源推进到影响 Agent 行为与界面，扩展能力更强，也意味着插件审查、权限边界和遥测策略需要同步升级。
- 建议动作：先在隔离环境审计 Mod 的事件监听、工具改写和 UI 权限，再决定是否进入团队默认配置；对内置侧边 Agent 的遥测前提保持明确提示。
- 来源：[Claude Code 官方 v2.1.287 发布页](https://github.com/anthropics/claude-code/releases/tag/v2.1.287)；[Claude Code 官方 changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md#21287)

### A｜Anthropic 发布 Claude-shaped science 案例与开源科研工具 BootLoops

哈佛物理学家 Matthew D. Schwartz 在 Anthropic 官方研究文章中总结三个月内用 Claude 与 BootLoops 推进 18 个领域、36 份手稿的工作方式。BootLoops 1.0 把精确积分、递推证明、贝叶斯证据计算和误差认证等工具连同验收协议开源，强调模型适合承担可计算、可核验的技术工作，而科学价值仍需领域专家判断。

- 事件日期：2026-10-01
- 重要性：它给出一种可复用的科研 Agent 工程模式：工具、验证门槛、独立复核和专家品味分离，避免把模型的自信结论直接当成科学发现。
- 建议动作：评估 BootLoops 的自测试、许可证和可复现示例；借鉴其“结果必须通过独立路线验证”的协议，但不要把案例规模或作者结论泛化为无人监督科研能力。
- 来源：[Anthropic 官方研究文章](https://www.anthropic.com/research/claude-shaped-science)；[BootLoops 官方 GitHub 仓库](https://github.com/BootLoops-ai/bootloops)

## 今日前沿论文

### A｜ArtifactWorld 用视频扩散规模化修复 3DGS 伪影

ArtifactWorld 建立 3DGS 伪影分类并构造 10.75 万对视频训练数据，以同构预测器生成伪影热图，再在共享视频扩散骨干内完成按强度、跨时间一致的局部修复。

- 论文日期：2026-09-30
- 重要性：它把稀疏视角 3DGS 的逐场景清理推进为可规模化的生成式后处理，适合房产、室内空间和数字孪生资产管线。
- 建议动作：优先复现已发布的两阶段推理与 1.28K 基准子集，重点检查几何保真、跨管线泛化和大视角变化；等待完整训练数据与训练代码。
- 来源：[arXiv 官方论文页](https://arxiv.org/abs/2604.12251)；[论文官方代码仓库](https://github.com/fyting/ArtifactWorld)

### A｜Matrix-Game 3.0 以长时记忆实现实时交互世界生成

Matrix-Game 3.0 结合游戏、合成和真实视频数据，通过自纠错训练、相机感知记忆、多段自回归蒸馏与模型压缩，报告 5B 模型可在 720p 下最高达到 40 FPS，并维持分钟级时空一致性。

- 论文日期：2026-09-30
- 重要性：它展示了世界模型从离线短视频走向可交互、实时和长时运行的工程路线，对游戏原型、空间 Agent 和机器人仿真有直接参考价值。
- 建议动作：在公开代码和完整硬件信息出现前保持观察；重点核验动作累积误差、物理一致性、端到端延迟和从游戏数据到真实环境的迁移。
- 来源：[arXiv 官方论文页](https://arxiv.org/abs/2604.08995)

### A｜SplitMoE 为视频扩散打破均匀路由陷阱

SplitMoE 将视频生成的专家池拆分为语义专家与通用专家，用原型引导路由和拉推正则替代强制均匀负载，使长尾语义自然聚类，并在相同激活参数预算下改善收敛、路由连贯性和视频质量。

- 论文日期：2026-09-30
- 重要性：它为大规模视频生成和视频世界模型提供更符合时空冗余与语义长尾的稀疏扩展方式，可能在不同比例增加单次激活计算的情况下提升容量。
- 建议动作：等待代码并核验吞吐、显存和长视频稳定性；特别测试专家负载偏斜是否在真实训练中造成热点、退化或难以扩展的通信成本。
- 来源：[arXiv 官方论文页](https://arxiv.org/abs/2609.38140)
