## 今日重点

### 1. AWS Agent Registry 正式可用，集中治理 Agent、工具与技能

AWS 宣布 Agent Registry 正式可用，为企业提供可搜索、可审批的 Agent 能力目录，支持 MCP、A2A Agent Card、Markdown 技能和自定义 JSON 资源，并提供语义与关键词搜索、访问控制、生命周期和合规元数据。

**为什么重要：** 企业 Agent 的瓶颈正在从“能否构建”转向“能否发现、复用、审计和停用”。

**建议：** 用官方样例登记一个 MCP Server、一个 A2A Agent 与一个技能，验证审批、权限隔离、版本回滚和运行时发现。

- [AWS 官方公告](https://aws.amazon.com/blogs/machine-learning/manage-agents-tools-and-skills-at-scale-with-aws-agent-registry/)
- [AWS 官方示例仓库](https://github.com/awslabs/agentcore-samples/tree/main/01-features/07-centralize-and-govern-your-ai-infrastructure/03-registry)

### 2. 英国启动 1 亿英镑主权 AI 采购竞赛

英国政府启动 Sovereign AI 研发采购计划的首批四项竞赛，覆盖 NHS 工作流、AI 计算效率、国防系统中的前沿 AI 接入，以及 Agent 安全与韧性测试。

**为什么重要：** 产业扶持从补贴推进到具有明确公共部门问题和采购路径的需求侧验证。

**建议：** 跟踪竞赛细则、入选企业、合同金额和验收指标，重点关注 Agent 安全工具能否形成可复用的政府采购标准。

- [英国政府官方公告](https://www.gov.uk/government/news/100-million-competition-to-back-british-ai-companies-to-fix-public-services)

### 3. ChatGPT Ads 年化收入运行率达到 10 亿美元

OpenAI 官方宣布，ChatGPT Ads 上线不足 200 天后年化收入运行率达到 10 亿美元，并向印度、欧洲、中东和北非扩展自助广告购买。

**为什么重要：** 广告已进入可量化规模阶段，可能改变通用 AI 助手的免费层经济模型和产品治理重点。

**建议：** 跟踪广告标识、推荐与自然回答隔离、地区扩张、广告主效果口径和用户留存变化。

- [OpenAI 官方公告](https://openai.com/index/expanding-access-to-ai-with-chatgpt-ads)
