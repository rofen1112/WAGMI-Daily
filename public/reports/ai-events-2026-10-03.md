## 今日重大事件

### A｜OpenAI 发布 GPT-6 家族生产选型与长任务实践指南

OpenAI 将 Astra、GPT-6.1 Sol 与 Luna 分别定位于最高难度推理、复杂编程研究与规模化重复任务，并建议以提示词缓存、上下文压缩、推理强度和速度模式平衡效果、成本与延迟。

- 事件日期：2026-10-02
- 重要性：模型选择开始转向按任务难度、成功成本和延迟分层，直接影响 Agent 路由、评测与预算设计。
- 建议动作：建立三类模型的同任务对照，记录成功率、端到端时长与每次成功成本。
- 来源：[OpenAI 官方指南](https://openai.com/index/practical-guide-building-gpt-6/)

### A｜苹果将因 AI Agent 风险收紧 macOS 完全磁盘访问

苹果表示将为 macOS“完全磁盘访问”增加更明确的用户授权控制，并指出自主 AI Agent 会放大这一高权限暴露文件、邮件、消息和浏览历史的风险。

- 事件日期：2026-10-02
- 重要性：操作系统正在把 Agent 的广泛数据访问视为独立安全边界。
- 建议动作：盘点完全磁盘访问依赖，改用最小权限、按任务授权和可撤销审计。
- 来源：[Apple Developer 官方公告](https://developer.apple.com/news/?id=p6zjojqw)

### A｜Meta 开源 Muse Gadgets SDK 并推出 Home Link 设备

Meta 开放 ESP32 固件与 Linux SDK，让开发者构建提醒屏、HDMI 棒和触屏设备，并推出连接电视、音箱、灯光和打印机的 Muse Home Link。

- 事件日期：2026-10-02
- 重要性：常驻个人 Agent 正从电脑软件扩展到低成本实体终端和家庭设备。
- 建议动作：在隔离网络审计设备发现、认证、技能权限与升级机制。
- 来源：[官方 GitHub](https://github.com/facebookincubator/muse-gadget-sdk)、[The Verge](https://www.theverge.com/tech/1004330/meta-muse-ai-gadgets-home-link)

### A｜Epoch AI 测算未来硬件可支撑数千万至上亿并发 Agent

Epoch AI 估算 2025 至 2027 年出货的高带宽内存硬件全部部署后，可能支撑约 3,000 万至 1.7 亿个并发前沿模型 Agent，同时指出对应 API 等价支出可能极高。

- 事件日期：2026-10-02
- 重要性：算力供给可能快于可付费需求增长，Agent 商业模式仍取决于真实工作负载价值。
- 建议动作：用每小时有效任务价值、利用率与单位成功成本建立自己的需求模型。
- 来源：[Epoch AI 官方分析](https://epoch.ai/publications/estimating-the-agent-population)
