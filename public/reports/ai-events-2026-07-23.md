## A 级事件

### 1. AMD 将向 Anthropic 投资最高 50 亿美元并部署 2GW MI450 算力

- **ID**：`ai-2026-07-22-amd-anthropic-2gw-partnership`
- **分类 / Boards**：Financing / Investment；AI Products / Models；Market / Business Models
- **摘要**：AMD 与 Anthropic 宣布多年战略合作，Anthropic 将从 2027 年上半年起部署最高 2GW 的 AMD Instinct MI450 系列 GPU 与 Helios 机架级系统；AMD 的最高 50 亿美元股权投资与部署里程碑挂钩，双方还将用 Claude 优化 Instinct 工作负载与 ROCm 软件。
- **为什么重要**：这不是普通融资，而是资本、数十亿美元级算力采购与软件协同绑定的“循环式”基础设施交易，将直接改变 NVIDIA 之外的前沿模型算力供给格局。
- **行动**：把模型供应商的芯片集中度、资本绑定、交付里程碑和 ROCm 迁移成本纳入基础设施风险评估。
- **核验**：[AMD 官方公告](https://ir.amd.com/news-events/press-releases/detail/1292/amd-and-anthropic-announce-strategic-partnership-to-deploy-up-to-2-gigawatts-of-amd-instinct-mi450-series-gpus) · [Reuters](https://m.investing.com/news/stock-market-news/amd-to-invest-up-to-5-billion-in-anthropic-wsj-reports-4805909?ampMode=1) · [ROCm/ROCm](https://github.com/ROCm/ROCm)
- **仓库候选**：`ROCm/ROCm`（verified）

### 2. 美国 Genesis Mission 获超 50 亿美元承诺并扩展为跨部门 AI 科研计划

- **ID**：`ai-2026-07-22-us-genesis-mission-ai-science`
- **分类 / Boards**：Funding / Investment；AI Security / Governance；AI Agent；Market / Business Models
- **摘要**：白宫宣布超过 50 亿美元联邦承诺，把由能源部发起的 Genesis Mission 扩展为 15 个以上联邦机构共同参与的 AI for Science 计划，并公布 278 个项目。微软另投入 6000 万美元，建立 SPARK 协调中心，以 Azure、Microsoft Discovery、工程服务和安全治理支持国家实验室。
- **为什么重要**：AI for Science 正从单点模型和实验室合作升级为国家级数据、算力、科研设施与治理平台，覆盖生物医药、材料、能源、数字孪生和基础设施。
- **行动**：跟踪公开挑战、数据集、国家实验室合作入口和 Microsoft Discovery agent catalog，优先识别可复用的科研 Agent 与数字孪生资产。
- **核验**：[白宫公告](https://www.whitehouse.gov/releases/2026/07/45502/?query-11-page=3) · [Microsoft 官方博客](https://blogs.microsoft.com/blog/2026/07/22/powering-americas-genesis-mission-microsofts-commitment-to-scientific-discovery/) · [NIH Bio Genesis](https://www.nih.gov/about-nih/nih-director/statements/statement-launch-bio-genesis-mission-nihs-component-national-genesis-mission) · [microsoft/discovery](https://github.com/microsoft/discovery)
- **仓库候选**：`microsoft/discovery`（verified）

### 3. Cursor Router 将模型路由变成团队级成本控制层

- **ID**：`ai-2026-07-22-cursor-router-launch`
- **分类 / Boards**：AI Coding；AI Agent；Market / Business Models
- **摘要**：Cursor 为 Teams 与 Enterprise 推出 Router，按请求内容、上下文、复杂度和领域在模型间自动路由，并提供 Intelligence、Balance、Cost 三种优化模式。Cursor 称早期企业客户成本降低 30%–50%，在线 A/B 测试在保持前沿质量的同时节省约 60%。
- **为什么重要**：AI 编程工具的竞争从“接入哪一个模型”转向“谁掌握生产流量、满意度与每次提交成本数据，并能自动调度模型”。
- **行动**：用真实任务复测质量、成本、缓存命中和模型透明度；企业启用前确认允许/阻止模型、强制策略与审计日志。
- **核验**：[Cursor 官方博客](https://cursor.com/blog/router) · [Cursor changelog](https://cursor.com/changelog/router) · AI风向标 / 内部发现源
- **仓库候选**：Cursor Router CLI/SDK integration（pending，官方未给出稳定公开 repo）

### 4. Claude Security 插件在 Claude Code 中进入 Beta

- **ID**：`ai-2026-07-22-claude-security-plugin-beta`
- **分类 / Boards**：AI Security / Governance；AI Coding；AI Agent
- **摘要**：Anthropic 发布 Claude Security 插件 Beta，可在提交前扫描代码变更，也可从终端执行全代码库扫描，复用开发团队现有的 Claude 推理配置。
- **为什么重要**：安全审查被放进编码 Agent 的同一终端闭环，能够缩短提交前漏洞反馈周期，但也会把安全判断绑定到模型、提示与权限配置。
- **行动**：先在非关键仓库与 SAST/依赖扫描做并行对照，记录误报、漏报、扫描范围和敏感代码暴露边界，再决定是否进入必经检查。
- **核验**：[Claude 官方公告](https://x.com/claudeai/status/2079990597973057691) · [产品说明入口](https://x.com/claudeai/status/2079990599415922802) · AI风向标 / 内部发现源
- **仓库候选**：Claude Security plugin（pending，未解析到稳定公开插件路径）

### 5. Claude Code 2.1.218 将代码审查移入后台子 Agent 并强化安全边界

- **ID**：`ai-2026-07-22-claude-code-21218`
- **分类 / Boards**：AI Coding；AI Agent；AI Security / Governance；Workflow / Tutorial / Usage Tips
- **摘要**：2.1.218 把 `/code-review` 改为后台子 Agent，修复 Windows `C:\Users\...` 路径被错误转义、PR 事件丢失、插件与设置无障碍问题，并强化不可信 agent hooks、IDE 沙箱限制和 auto mode 的危险命令判定。
- **为什么重要**：后台审查减少主对话污染，但权限、工作区信任和自动模式的行为同时变化，团队升级需要功能与安全回归测试。
- **行动**：升级后重点复测 Windows 路径、后台审查目标、PR 事件、agent hooks 信任边界与 auto mode 删除命令策略。
- **核验**：[Anthropic 官方 changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md#21218) · [Raw changelog](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) · AI风向标 / 内部发现源
