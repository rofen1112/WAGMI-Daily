## 访客与模型

正式站仅提供 API 自动建模，不提供本机 Codex 接力操作或私人历史案例导入。每个浏览器使用不可伪造、HttpOnly、SameSite=Lax、HTTPS Secure 的会话 Cookie；项目、图片、任务和版本存入 `.local-ai-lab-public/visitors/<session>/`，不会打开开发版 `.local-ai-lab/`。清除 Cookie、换浏览器或设备后无法找回该会话项目，应主动导出方案。

模型参数、结构校验、真实 2D/3D 截图复核及失败不保存的门禁沿用原实现。离线回归通过不代表模型还原质量达标；11 月 5 日真实 API 测评仍为未通过，不覆盖其失败记录。保持编辑器开启可提交实际预览；失败原因继续如实显示。

本机全体访客共用一个模型执行槽；每次任务沿用原有调用、修复和复核预算。正式入口增加持久化接单上限：上海日全站 20 次、每个会话 5 次；失败输入退还接单次数，幂等重试不重复扣减。每会话最多 100 个项目、100 张图片；最多保留 32 个同时驻留的工作空间，空闲超过 15 分钟且没有活动任务的实例可释放，磁盘项目不删除。没有账户跨设备恢复和自动清理历史项目功能。

代理只转发指定 API 与 viewer 路径；拒绝跨站调用、目录穿越、Codex operator 接口、私人基准载入及超限请求。开发密钥、原案例和数据库不进入静态产物、Git 或公开报告。
