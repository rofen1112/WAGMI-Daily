# Floorplan-Editor · 入口与项目管理

本轮按用户六项反馈增加入口层级并整理编辑器 UI，继续仅在独立 `codex/ai-lab` 开发。主站仓库、正式部署和既有模型数据保持各自所有权；正式站菜单接入由主项目审阅后完成。

## 开发版入口

1. `http://127.0.0.1:5186/#/today`：网站导航中的“AI 实验室”。开发服务器只读代理当前8080站点的公开`/data/main` JSON，不复制主项目数据，不代理管理API；该路径仅允许GET/HEAD。
2. `#/ai-lab`：AI 实验室应用目录。目前只列实际可用的 Floorplan-Editor。
3. `#/ai-lab?tool=floorplan3d`：Floorplan-Editor 项目管理，支持项目搜索、排序、参考案例与新建入口。
4. `#/ai-lab?tool=floorplan3d&view=new`：新项目编辑界面；仅打开页面不会产生空数据库项目或付费生成。
5. `#/ai-lab?tool=floorplan3d&projectId=...`：打开已有项目，保留原深链接和任务恢复。没有tool的旧projectId链接仍兼容。

## 六项改动

- 网站入口、应用目录和项目管理分层；应用目录不是编辑器的项目列表。
- 应用品牌统一为`Floorplan-Editor`，使用用户提供图案的暗壳原logo，不重新绘制。
- 项目管理采用卡片布局，显示实际项目、日期、版本和任务状态；已保存项目的平面缩略图从当前scene/state绘制，懒加载、缓存且最多3路请求，不启动缩略图WebGL实例。
- 项目侧栏快捷开关移到左侧预览工具栏最前；移动抽屉通过自身关闭按钮、遮罩与Esc退出。
- 编辑器背景为纯色，移除重复的内嵌标题、项目名和摘要；比例来源、历史参考提醒和属性统计仍可访问。
- 底部及主要画布工具统一为线性SVG图标，保留中文悬停说明、可访问名称和选中态。

真实Three.js场景保留模型物理阴影。背景平面只接收阴影，交互视图不再有背景色带；工作流自动复核仍使用原固定日光、1280×960及原背景，以免将UI改版混入历史模型评测。此轮没有更改户型几何、家具材质、比例算法或模型提示。

设计沿用`apple-design` Skill，并使用Codex Design MCP进行第3轮迭代及复核。参考图只用于布局：未加入未实现的模板库、Rhino/NURBS导出或虚构应用。

## 实际验收

19项引擎、19项前端交互、2项真实Chromium布局回归通过；布局覆盖编辑器3个视口及项目管理2个视口，0跳过。类型检查、lab构建和public/admin/lab隔离检查通过。

真实浏览器从5186首页导航开始，依次点击实验室目录、应用卡片、项目管理、新建界面、已有项目，并验证前进/后退、返回目录后重新进入不自动打开旧项目。项目快捷开关位于预览工具栏左端：侧栏收起时x=12，仍可直接展开。2D/3D均已核对纯色背景、无重复标题、线性工具与可见品牌logo；错误/警告日志为空。

验收前后35个项目、20个已保存方案的导出哈希、版本与最新job ID一致；点击新建未提前创建项目或触发模型。开发首页公开JSON返回200，非只读方法返回405并声明`Allow: GET, HEAD`。主站8080仍为原发布版本；没有执行主项目发布。

## 已保存空间的精简模式（2026-11-05）

按用户最新要求，已有有效场景进入本地编辑模式：不再挂载右侧创作面板、后续 AI 生成或对话修改入口，也不保留重新打开该面板的按钮；右侧宽度全部归还画布。移动端只保留项目抽屉，专注模式及 Esc 恢复以当前可用面板为准。

新建项目首次上传、比例校准、生成及候选复核流程保留，保存成功后切换到精简编辑器。任务错误与保存/导出操作的即时反馈仍需可见；后台校验、历史任务、模型配置与项目数据不因界面简化而删除。

画布上的“说明与提醒”浮层与左下角模型名称提示移除。2D/3D 切换、原图、本地家具和房间编辑、测量、属性、保存及 JSON 导出继续保留。此轮不更换三维模型、材质或灯光；写实展示的范围和家具资产边界另见 `ai-lab-realistic-rendering-plan.md`。

## Agent 工作台与线性平面（2026-11-05）

后续用户指定开发阶段由当前 Codex 聊天执行，默认外部模型调用已关闭。新建空间右侧采用 Agent 任务时间线、实际事件增量、附件与要求输入，并明确显示接力状态。五阶段为尺寸核对、识别结构、搭建空间、检查复核、方案完成；依据不足时通过画布比例尺入口选择两点校准或手动比例。事件与阶段来自真实任务记录，不模拟模型打字或推理输出。

左侧改为线性图标导航与按需展开的上下文面板：项目、视角、家具、材质属性、户型导入和比例使用真实已有功能。2D/3D 切换移至空间标题工具栏，通过受限命令桥与内嵌编辑器双向同步；不保留重复的画布内切换器。

2D 默认采用白底线稿：移除展示地纹与家具色块，保留墙门窗、家具轮廓、房间标签和尺寸。原始几何与材质数据不变，3D 保留原材质/灯光；自动复核截图仍按原绘图合同生成并恢复用户线稿状态。当前阶段没有全量替换45类家具模型。

## 左侧搭建面板与沉浸漫游（2026-11-05）

家具库与材质/对象属性从画布浮层改为左侧停靠面板，通过左侧导航打开。两者复用原编辑器的家具目录、选择、编辑和撤销逻辑，占用独立布局列；空间画布随面板展开调整宽度，不再被面板覆盖。画布内重复的家具库和属性入口移除。

进入漫游后收起编辑外壳、工具、面板、灯光选择、比例尺和导航浮层，只呈现空间。退出入口放在外层标题工具栏的2D/3D旁边；点击退出或按Esc返回原来的编辑布局。漫游状态由实际三维视图回传，父页面不通过按钮点击自行假定已进入或已退出。桌面漫游使用WASD/方向键移动、按住鼠标拖动转向，保留鼠标直接点击标题栏退出，不依赖内置浏览器的鼠标锁定能力。触屏通过画面左侧拖动移动、右侧拖动转向，无显式摇杆。

本轮仅整理展示与交互：不更改比例、户型几何、家具材质、模型执行方式或历史案例。设计使用Codex Design MCP迭代计划与复核清单，沿用白底、线性图标和按需展示的界面规则。

验收：25项引擎检查（含原三例兼容）与25项前端/Chromium布局检查通过，lab类型检查与构建通过。真实浏览器验证了家具/属性左侧停靠、画布选中联动、桌面拖动转向、标题栏按钮和Esc退出恢复，以及390px窄屏无横向溢出、户型完整居中。内置浏览器不支持的鼠标锁定不再作为内嵌漫游的依赖，最终拖动验证无新增错误。触屏透明双区手势保留离线行为覆盖，尚未在实体触屏设备验收。操作前后42个项目、41个已保存场景的版本、job ID与导出哈希一致；未创建生成任务。
